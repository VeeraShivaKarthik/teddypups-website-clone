# TeddyPups U.A.E. — Website Recreation

A responsive React + Vite recreation inspired by the supplied TeddyPups reference website.

## Run locally
1. Install Node.js 18 or newer.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Production build
Run `npm run build`. The production files are generated in `dist/`.

## Deploy to Vercel
1. Import this GitHub repository at https://vercel.com/new.
2. Framework preset: Vite.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Deploy.

## Project structure
- `index.html` — document shell and metadata
- `src/main.jsx` — page sections and interactive React components
- `src/styles.css` — responsive styling and layout

## Implemented interactions
- Responsive navigation menu
- Puppy breed filters
- Puppy enquiry links to WhatsApp
- Expand/collapse FAQ
- In-page section navigation
- Floating WhatsApp contact link
